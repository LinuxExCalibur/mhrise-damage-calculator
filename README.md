# 怪猎崛起伤害计算器 · MHRise Damage Calculator

用于《怪物猎人 崛起 / 曙光》的配装伤害计算器。核心用途是把**会心流配装**和**攻击流配装**放在一起对比，一眼看出哪套期望伤害更高。

纯单文件网页，离线可用，无需安装任何依赖。

## 在线使用

```
https://LinuxExCalibur.github.io/mhrise-damage-calculator/
```

也可以把 `index.html` 下载到本地，双击用浏览器打开。

## 功能

- **双配装并排对比**：配装 A（会心流）与配装 B（攻击流），同一目标下直接比较期望伤害
- **非会心 / 会心 / 期望**三种伤害分别给出，物理与属性分开计算
- **部位肉质**：内置 **78 只大型怪物**（含曙光 DLC、霸主、怪异克服个体），每只 5–15 个部位
- **斩味倍率**：红橙黄绿蓝白紫，物理与属性分别套用
- **会心体系**：基础会心、看破、弱点特效、超会心、会心击【属性】Lv1–3
- **软化模拟**：开启后按 `0.75 × 肉质 + 25` 重算肉质
- **怪物补正**：可手动填入怒后 / 全体防御率
- 可选属性类型（无 / 火 / 水 / 雷 / 冰 / 龙）与额外攻击力、攻击力百分比、额外属性值

## 计算公式

```
真实攻击力 = 显示攻击力 ÷ 武器倍率 + 攻击技能固定值 + 额外攻击力
实际攻击力 = 真实攻击力 × (1 + 攻击技能百分比 + 自定义百分比)

物理伤害 = 实际攻击力 × (动作值 ÷ 100) × 斩味物理倍率 × (肉质 ÷ 100) × 会心倍率 × 怪物补正
属性伤害 = (显示属性值 ÷ 10 + 额外属性值) × 斩味属性倍率 × (属性吸收 ÷ 100) × 属性会心倍率 × 怪物补正
```

**会心倍率**：正会心 1.25，超会心 Lv1/2/3 → 1.30 / 1.35 / 1.40；负会心 ×0.75。

**期望伤害**

- 会心率 ≥ 0：`非会心 × (1 − 会心率) + 会心 × 会心率`
- 会心率 < 0：`非会心 × (1 − |会心率|) + 非会心 × 0.75 × |会心率|`

## 与《世界》版的差异（重要）

崛起在技能数值上与世界差得很远，本计算器按**崛起**的数值实现：

| 技能 | 世界 | 崛起 |
|---|---|---|
| 攻击 Lv4–7 | +12/+15/+18/+21，倍率 1.05–1.10 | **+7/+8/+9/+10**，倍率 1.05–1.10 |
| 弱点特效 Lv1–3 | +10/+15/+30 | **+15/+30/+50** |
| 会心击【属性】 | ×1.35 / ×1.55（两档） | **×1.05/1.10/1.15（三档）** |
| 超会心 | 1.30/1.35/1.40 | 同 |
| 看破 Lv7 | +40 | 同 |

**属性列顺序也不同**：Kiranico 崛起页面的属性列是 **火 / 水 / 冰 / 雷 / 龙**（冰在雷之前），世界是 火/水/雷/冰/龙。本项目的抓取脚本已按崛起页面的实际列序解析。

## 数据覆盖

**78 只大型怪物**，覆盖崛起本体 + 曙光 DLC，包括霸主个体与怪异克服个体。

抓取脚本按「页面第一张含 `hit_slash` 图标的表格」定位肉质表，只取 `State = 0`（基础状态）的行；多形态怪物（如怪异克服个体）只保留基础形态数值。

### 部位名规范化

Kiranico 的部位单元格里会混入日文注释（例如 `胴_肉質(操竜受付用)`、`J：腕鬼火`），直接抓取会得到不可读的部位名。项目按 `tools/part-name-map.json` 做了如下替换：

| 原始（Kiranico） | 本项目 |
|---|---|
| 胴_操竜嘘アタリ用 / 胴_肉質(操竜受付用) / 胴体(操竜受付用) / 胴体_肉質(操竜偽アタリ) | 躯干 |
| 尻尾_肉質(根本) | 尾巴（根部） |
| 右翼脚_肉質 / 左翼脚_肉質 | 右翼脚 / 左翼脚 |
| J：腕鬼火 | 前肢・鬼火 |
| 顔鬼火 | 头部・鬼火 |
| L：ガスだまり | 瓦斯聚集处 |
| 希少用先端 | 尾巴尖 |
| 颈・背部 | 颈部・背部 |

另有 7 行在页面上没有可用部位名（炽妃蜘蛛、妃蜘蛛、天狗兽、绯天狗兽、雪鬼兽、刚缠兽 各 1 行，以及将军镰蟹的「不擅长」行），已剔除。其中雪鬼兽那一行与「本体」数值完全相同，属于重复行。

同一怪物内同名部位会加序号区分，如「爪①」「爪②」「腿（丝）①」。

### 部位备注

鼠标悬停在部位按钮上会显示该部位的说明，选中后按钮下方也会同步显示：

| 部位写法 | 备注 |
|---|---|
| `头部（破坏）` | 部位破坏后的肉质，数值与破坏前不同 |
| `下颚（软化）` | 钩爪软化后的肉质，数值比软化前高 |
| `爪①` / `爪②` | 源数据中的同名重复行：①是页面上先出现的那组，②是另一组；Kiranico 没有标注具体状态 |
| `腹部（茧化状态）` | 括号内是该部位的状态或形态 |
| 其他普通部位 | 无特殊备注 |

## 已知取舍

- **武器倍率**沿用世代通用表，其中轻弩/重弩/弓的倍率未从崛起数据源逐一核对。若你的武器类型是远程，建议用「额外攻击力」手动校正。
- **斩味倍率**采用与世界相同的表，崛起未单独核对；白斩 1.32、紫斩 1.39 与社区常用值一致。
- 只保留 `State = 0` 的肉质行，未收录怒后 / 部位破坏后的肉质变化。
- 软化公式统一为 `0.75 × 肉质 + 25`，未按怪物区分 ±5 的个体差异。
- 动作值（MV）需手动输入，未内置各武器招式表。
- 怪异探究任务的「怪异化」属性吸收变化未建模。
